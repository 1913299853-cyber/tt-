# ISOTYPE｜项目定位与研究框架

## 1. 为什么独立成项

本知识库将 ISOTYPE 视为一种基础设计方式/视觉语言，而不是一种与时间轴型、混合型、文字型并列的信息图形类别。

它可能被运用到不同的信息图形类型中，因此研究重点不是给它归类为某一种版式，而是理解它如何构建视觉符号、组织信息并传达含义。

## 2. 核心研究问题

- ISOTYPE 的概念边界和历史语境是什么？
- 图像符号如何被设计、选择和标准化？
- 符号如何表示对象、类别、数量或行动？
- 重复符号、比例、排列和组合如何表达数据？
- 图像、文字、图例和说明之间如何分工？
- 如何保证符号易读、可比较且不产生歧义？
- ISOTYPE 的方法如何应用于当代信息设计？

## 3. 五个分析维度

| 维度 | 需要研究的问题 |
|---|---|
| 符号语义 | 一个符号代表什么，含义是否稳定？ |
| 符号语法 | 符号如何重复、组合、排列和连接？ |
| 数量表达 | 数量通过符号个数、大小或其他方式如何呈现？ |
| 图文关系 | 标题、标签、图例和说明如何辅助理解？ |
| 视觉叙事 | 信息如何排序、比较、解释并形成结论？ |

## 4. 案例分析模板

每个案例至少记录：
- 案例名称、设计者/机构、时间、来源
- 原始图像
- 主题与传播目的
- 数据来源及统计口径
- 符号清单及其语义
- 符号重复、组合、排列规则
- 数量与比例的表达方式
- 图文关系和阅读路径
- 优点、局限与可迁移原则
