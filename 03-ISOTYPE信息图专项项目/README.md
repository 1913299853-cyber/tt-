# 03-ISOTYPE信息图专项项目

## 项目定位

ISOTYPE 在本知识库中不归类为“信息图形的一种”，也不放入 02-信息图形类型案例。它作为一种独立的基础设计方式/视觉语言进行专项研究。

本项目关注：如何通过经过设计的图像符号、重复与组合、数量关系、图文关系和视觉规则，将复杂信息转化为易于理解的视觉表达。

> 研究边界：以上是本项目的工作定位。具体历史定义、术语范围、方法原则与案例结论，应在后续资料和案例研究中逐步核实、补充，不把未经来源支持的说法写成定论。

## 与其他目录的关系

- **01-信息图形数据逻辑：** 研究信息如何组织、统计与叙事。
- **02-信息图形类型案例：** 研究不同信息图形类型的具体表现。
- **03-ISOTYPE信息图专项项目：** 研究可被用于信息表达的基础视觉设计方式与符号系统，不将其当作与时间轴、混合型等并列的图形类型。

## 更新原则

1. 以可靠资料和用户提供的案例为依据。
2. 每个案例单独记录来源、图像、符号含义、数据关系和设计方法。
3. 区分历史事实、来源陈述、画面观察与分析推断。
4. 从案例中提炼可复用的符号设计、数量表达、图文协作和视觉组织原则。
5. 新发现应回写本项目的基础方法文档，并保留修订记录。
