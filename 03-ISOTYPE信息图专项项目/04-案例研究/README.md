# ISOTYPE｜案例研究

本目录专门保存 ISOTYPE 相关案例，与 02-信息图形类型案例相互独立。

## 每个案例建议包含

- 案例原图或图像文件
- 独立分析报告（Markdown）
- 来源链接、作者/机构、年代等出处信息
- 符号清单与编码说明（必要时单独成表）

## 分析报告模板

复制以下结构建立独立案例报告：

1. 基本信息与来源
2. 主题和传播目的
3. 数据来源与统计口径
4. 符号系统：符号、语义、单位
5. 视觉语法：重复、组合、排列、连接
6. 数量表达与统计关系
7. 图文关系与阅读路径
8. 视觉编码：点、线、面、色彩、文字
9. 优点、局限与误读风险
10. 可复用的基础设计原则
11. 待核实问题

完成案例后，回写本专项项目的基础设计方式、视觉语法和符号编码文档。
