# ISOTYPE｜基础设计方式与视觉语法

> 本文是研究工作文档。以下条目是分析框架，不代表所有规则已被历史资料或案例证实。

## 1. 基础设计方式

研究视觉符号如何代替、简化或补充文字表达，以及符号如何被组织成可读的信息系统。

## 2. 视觉语法观察表

| 视觉要素 | 研究问题 |
|---|---|
| 图像符号 | 符号代表对象、人物、类别还是概念？ |
| 重复 | 重复一个符号是否代表多个单位？ |
| 大小 | 大小差异是否代表数量或等级？ |
| 排列 | 横向、纵向、网格或分组排列分别表达什么？ |
| 组合 | 多个符号组合后是否形成新的含义？ |
| 颜色 | 颜色表示分类、状态还是强调？ |
| 文字 | 标题、标签、图例和说明如何消除歧义？ |
| 空间 | 距离、分区、对齐和留白承担什么作用？ |

## 3. 数量表达需要特别核查

分析案例时，必须辨别：
- 一个符号是否代表一个固定数量单位；
- 是否存在部分符号或比例符号；
- 符号大小是否变化，变化是否具有明确数量含义；
- 图形数量与原始统计值能否一一对应；
- 图例是否说明单位、比例和舍入方式。

不能仅凭图像“看起来更大/更多”就推断具体数值。

## 4. 与统计图形的关系

ISOTYPE 的视觉符号系统可能与统计图形共同出现。分析时应分清：
- 统计计算产生的数据结果；
- 符号系统对数据结果的视觉转译；
- 帮助阅读的版式与叙事设计。

## 5. 待案例验证

- 符号标准化的具体规则
- 数量表达的常见模式及边界
- 图像与文字的协作方式
- 不同主题下符号系统的可迁移性
