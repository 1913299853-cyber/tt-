# 05｜Gestalt 格式塔视觉组织规律

本目录研究格式塔心理学中与视觉知觉、图形组织和信息图设计有关的规律，建立“理论定义—知觉机制—视觉案例—设计分析—实践经验”的资料库。

## 分类说明
本库采用 **10 条核心规律 + 6 条扩展原则/现象** 的工作分类，共 16 个研究条目。格式塔规律并无学界统一认可的固定总数；不同教材、研究综述和设计指南的纳入范围、命名及层级并不一致。本分类仅为知识库管理框架。

### 核心规律（10）
1. 接近律（Proximity） 2. 相似律（Similarity） 3. 连续律／良好连续（Continuity / Good Continuation） 4. 闭合律（Closure） 5. 图形—背景组织（Figure–Ground） 6. 共同命运律（Common Fate） 7. 对称律（Symmetry） 8. 简洁律／良好形态原则（Prägnanz） 9. 共同区域律（Common Region） 10. 统一连接律（Uniform Connectedness）

### 扩展原则与知觉现象（6）
11. 平行律（Parallelism） 12. 同步律（Synchrony） 13. 整体涌现（Emergence） 14. 多稳态知觉（Multistability） 15. 熟悉性／意义性（Familiarity / Meaningfulness） 16. 焦点原则（Focal Point）

扩展条目并非全部与经典分组规律处于同一理论层级。例如整体涌现、多稳态属于知觉现象；焦点原则常见于设计指南，不应直接等同经典分组定律。
