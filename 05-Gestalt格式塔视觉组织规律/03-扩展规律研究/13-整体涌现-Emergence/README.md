# 整体涌现（Emergence）

## 定义
观察者可能先识别整体结构，再辨认构成它的局部元素。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
让数据点或图标共同形成总体轮廓，同时保持局部数据可读。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
这是知觉现象/研究主题，不宜等同单一分组定律。
