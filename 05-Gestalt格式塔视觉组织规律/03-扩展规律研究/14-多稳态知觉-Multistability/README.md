# 多稳态知觉（Multistability）

## 定义
某些刺激可支持多个相对稳定的知觉解释，观察者可能在解释间切换。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用于讨论双重图形、视角转换和多义表达。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
信息图应避免关键数据出现非预期歧义。
