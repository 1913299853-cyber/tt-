# 焦点原则（Focal Point）

## 定义
高显著性元素更容易吸引注意，成为优先关注的视觉焦点。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用有限的尺寸、对比、位置或留白突出最重要结论。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
常见于设计指南，不应不加区分地视为经典分组定律。
