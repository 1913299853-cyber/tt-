# 熟悉性／意义性（Familiarity）

## 定义
既有经验和熟悉模式会影响观察者组织、识别和解释视觉信息。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
使用读者熟悉的图表惯例、方向约定和符号，并配合图例说明。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
熟悉性受文化和专业背景影响，不应假设读者经验相同。
