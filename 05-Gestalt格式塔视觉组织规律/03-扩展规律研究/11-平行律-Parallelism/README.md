# 平行律（Parallelism）

## 定义
方向或结构相互平行的元素，在一些情境中更容易被感知为相关或同类。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用平行排列、线束或一致倾角表现同类对象或并行流程。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？
