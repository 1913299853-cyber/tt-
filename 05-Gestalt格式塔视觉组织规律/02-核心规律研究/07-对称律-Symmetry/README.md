# 对称律（Symmetry）

## 定义
具有对称关系的部分更容易被组织为相互关联的整体。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用于对照图、镜像比较、中心辐射图和成对布局。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
对称不代表数据量或重要性相等，差异需明确标注。
