# 图形—背景组织（Figure–Ground）

## 定义
知觉会将视觉场组织为突出的对象（图形）及其衬托区域（背景）。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用明度、对比、留白、层级和遮挡突出主体，控制背景干扰。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
检查低对比、复杂背景和不同屏幕条件下的辨识度。
