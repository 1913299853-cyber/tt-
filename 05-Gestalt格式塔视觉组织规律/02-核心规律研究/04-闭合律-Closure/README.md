# 闭合律（Closure）

## 定义
轮廓不完整时，观察者可能在知觉上补全，使其成为较完整形状。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
适度使用留白、断续轮廓或局部遮挡，让读者识别整体符号。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
关键数据边界和图例不能依赖猜测补全。
