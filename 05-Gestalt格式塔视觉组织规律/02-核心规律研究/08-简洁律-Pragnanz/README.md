# 简洁律／良好形态（Prägnanz）

## 定义
知觉倾向于形成较稳定、规则、简洁和有组织的整体结构。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
减少不必要装饰，用清晰结构、层级和一致编码帮助读者把握整体。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
简洁不得牺牲数据精度、必要背景或关系真实性。
