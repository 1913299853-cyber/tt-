# 连续律／良好连续（Continuity）

## 定义
视觉系统倾向沿平滑、连贯方向组织线段和轮廓。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用连贯连线、曲线和对齐关系引导阅读路径，避免线条交叉造成误读。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
需结合箭头、节点、遮挡和布局明确方向。
