# 共同命运律（Common Fate）

## 定义
同向移动或发生相似变化的元素容易被知觉为一个整体。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
动态信息图中用同步运动或一致动画节奏表达同组数据。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
共同变化不等同真实因果关系。
