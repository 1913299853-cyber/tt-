# 统一连接律（Uniform Connectedness）

## 定义
通过线条、带状区域等视觉方式相连的元素通常被知觉为一组。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用连接线表示节点关系、流程依赖或图例对应。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
连接可能被误读为因果或层级，应说明连接语义。
