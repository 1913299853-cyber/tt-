# 接近律（Proximity）

## 定义
空间上彼此靠近的视觉元素更容易被知觉为同一组。

## 基本原理
观察者依据视觉线索组织信息；效果受其他线索、任务和情境影响。

## 信息图设计应用
用间距区分标题、注释、数据组和图例；组内间距小于组间间距。

## 设计分析问题
- 哪些元素被看作一组？分组是否符合信息结构？
- 使用了哪些视觉变量？是否与其他线索冲突？
- 读者能否识别类别、比较关系和阅读顺序？

## 使用边界
距离不是唯一线索；过度拥挤降低可读性，边框、颜色或语义也会改变分组。
