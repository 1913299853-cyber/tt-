## 常用信息图形案例库
按具体图形类型建立独立子目录，包含示例图、分析报告、数据结构、统计图形及应用、视觉编码、信息框架和叙事框架。

## 维护规则
- 总文档记录该类别的稳定定义、特征、判断方法，并随案例更新。
- 每个案例单独建立分析报告；保留原始图片和来源信息。
- 区分来源事实、分析推断和设计建议；未知信息标注“待核实”。
- 文件夹不能直接保存空目录，因此使用 README.md 或 .gitkeep 占位。
