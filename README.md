# 信息图形研究与案例库

用于系统整理五类信息图形及常用图形案例。每个案例独立存档，并反向更新所属分类的总文档。

## 五类信息图形
1. 编年型（Chronological）
2. 层级型（Hierarchical）
3. 编目型（Cataloged）
4. 字母表型（Alphabet）
5. 地理型（Geographical）

## 常用信息图形案例库
按具体图形类型建立子文件夹，记录示例图、分析报告、数据结构、统计图形及应用、视觉编码、信息框架和叙事框架。

## 维护原则
- 每条数据/事件一行，每种属性一列（适用时）。
- 区分来源事实、分析推断与设计建议。
- 新案例加入后更新对应分类总文档和案例索引。
- 不确定内容标注“待核实”。
