# 信息图形研究知识库

本仓库用于通过案例研究，建立信息图形的数据逻辑、图形类型、视觉编码与叙事方法体系。

## 当前主结构

### 01-信息图形数据逻辑
研究五类信息图形的底层组织逻辑：
1. 编年型信息图形
2. 层级型信息图形
3. 编目型信息图形
4. 字母表型信息图形
5. 地理图形信息图形

本目录只保存概念、分析框架、原则和方法，不保存案例图片。每份文档通过 Markdown 相对链接指向 02 中的案例分析报告。

### 02-信息图形类型案例
通过案例分析归纳具体信息图形类型：
1. 混合型信息图形（Mixed Charts）
2. 文字型/列表型信息图形（Informational / List Infographics）
3. 时间轴型信息图形（Timeline Infographics）

每种类型包含一份持续更新的说明文档和案例资料。案例增加后，回链更新 01 中相关的数据逻辑文档。

## 研究与更新原则
- 理论总结以用户提供的案例图及其分析为主要依据。
- 案例尚未支持的结论标注“待案例验证”，不把一般经验写成已经证实的分类规律。
- 区分图中可直接观察的事实、分析推断和待核实信息。
- 每个案例单独保存分析报告；原图放在 02 对应类型的案例目录。
- 01 中不复制案例图片，只使用相对路径链接到 02 的案例报告。
- 每新增案例，先完成案例报告，再更新对应类型说明文档和 01 中的相关理论文档。

## 历史目录
仓库早期版本中的五类分类目录和常用信息图形案例库暂时保留，作为历史资料结构；本次研究与更新以以上 01、02 两个主目录为准。
