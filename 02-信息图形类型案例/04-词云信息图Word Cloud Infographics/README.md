# 词云信息图（Word Cloud Infographics）

## 类型定位

词云信息图以词语或短文本作为主要视觉单元，通常通过文字的字号、位置、方向、颜色、字重或空间组合呈现文本中的词汇特征。词语出现频率或其他权重可以参与视觉编码，但不能仅凭画面大小就默认其编码的是词频。

词云可以作为独立的信息图形，也可以与插画、照片、地图、统计图形和说明文字组合。具体分类应以案例的主要信息组织方式和表达目的为依据。

## 重点观察维度

1. **文本来源与处理**：语料来源、文本范围、语言、分词方式、停用词处理、同义词归并及筛选规则。
2. **词项与权重**：词语如何选取；权重是词频、TF-IDF、人工评分，还是其他指标；权重是否有明确说明。
3. **视觉编码**：字号、面积、颜色、字重、方向、位置、字体及词语间距分别承担什么作用。
4. **空间组织**：随机/自由布局、轮廓约束、主题分组、层级组织或其他排布方式。
5. **阅读与叙事**：读者首先看到什么；是否突出核心词、主题群组、对比或语义关系；是否提供图例和阅读说明。
6. **可读性与准确性**：词语是否重叠、遮挡或难以辨认；视觉权重是否容易造成误解；是否能追溯数据处理过程。

## 分析时需要区分

- **观察事实**：画面中实际出现的词语、字号差异、颜色、排布和文字说明。
- **分析推断**：对词频映射、主题分组、视觉层级和设计意图的判断。
- **待核实信息**：语料来源、算法、权重计算、分词与清洗规则等无法从画面确认的内容。

## 案例报告建议结构

- 案例基本信息与来源
- 画面结构与词项观察
- 文本数据来源及处理流程（已知/未知）
- 权重指标与视觉编码关系
- 空间布局和阅读路径
- 信息表达效果与局限
- 可复用的设计方法
- 待核实问题

## 注意事项

词云擅长呈现词项的突出程度和整体词汇印象，但通常不适合单独表达精确数值、复杂关系或严格的比较结论。若使用字号/面积表示数量或权重，应明确编码规则及数据来源；必要时配合列表、图表或原文证据。
