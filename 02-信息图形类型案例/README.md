## 使用说明

- 每个类型目录用于归档该类型的标签说明、案例原图、基础数据和案例分析。
- 新增案例时，优先放入最符合其主要信息组织与视觉表达特征的类型；存在多种特征时，可在分析中注明复合属性。
- 分类是案例整理入口，不代表不同类型之间绝对互斥。
- ISOTYPE 作为独立设计方法/视觉语言另设专题研究，不作为本目录的类型分支。
