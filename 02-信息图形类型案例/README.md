## 案例分析流程
1. 保存用户提供的原始案例图，并记录来源。
2. 建立独立案例分析报告。
3. 区分图中事实、分析推断和待核实信息。
4. 更新本目录对应类型的说明文档。
5. 将可复用的数据逻辑与原则回链更新到01中的相关概念定义文档。

说明文档是动态总结，不是一次性定稿。
