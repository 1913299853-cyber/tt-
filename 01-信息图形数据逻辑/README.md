# 01-信息图形数据逻辑

本目录是五类信息图形的概念与方法文档区，不保存图片案例。

每份文档统一分析五个方面：
A. 基本的数据逻辑
B. 使用的统计图形与计算方式
C. 视觉编码（点、线、面、体、符号、色彩、文字等）
D. 数据/信息架构
E. 视觉叙事架构
