# 06 视觉编码

本项目偏重设计表达。本阶段把叙事中的信息关系转译为可感知、可阅读的视觉语言，并说明每种视觉形式承担什么信息功能。

## 编码维度
- 点、线、面、体：位置、连接、边界、区域、空间层次和体量表达
- 色彩：分类、强调、分组、连续数值或情绪氛围
- 文字：字体、字号、字重、行距、字距、对齐、层级与可读性
- 图像与图形：照片、插画、图标、纹理、图形符号及其组合
- 统计图形：根据数据结构和比较目的选择图表，不为装饰而使用
- ISOTYPE：符号设计、重复组合、数量表达及图文关系

## 编码说明表
每项视觉编码记录：对应字段/叙事信息、视觉变量、编码规则、设计理由、阅读效果、可能歧义。
