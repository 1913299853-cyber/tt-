# 02 主题内容分析

本阶段需要通过与大模型多轮沟通，辅助梳理主题内容和设计定位。大模型给出的分类属于分析建议，须结合资料与数据条件判断，不直接当作事实。

## 讨论重点
1. 主题的核心对象、事件、概念及其关系是什么？
2. 内容更接近编年型、层级型、编目型、字母表型、地理图形型，还是混合结构？判断依据是什么？
3. 适合什么信息图形类型：时间轴、地图、词云、文字型/列表型、统计图形、图像主导型等？
4. 适合平面插画风格、照片风格、图表风格、符号化风格，还是混合风格？
5. 可使用哪些具体标签？哪些标签不适合？理由是什么？
6. 主题是否存在清晰的时间、空间、分类、数量、人物或因果关系？

## 讨论记录
将每轮关键提问、模型建议、采用/不采用的判断及理由记录在本目录。建议至少比较两种不同的设计定位。

## 阶段产出
- 主题内容结构图/关键词
- 信息图形类型判断及依据
- 风格方向与标签清单
- 待验证问题
- 暂定设计定位
