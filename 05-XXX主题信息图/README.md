## 项目流程

1. [前期调研](./01-前期调研/README.md)：明确主题背景、研究问题、受众和资料范围。
2. [主题内容分析](./02-主题内容分析/README.md)：与大模型讨论主题属性、信息图形类型、视觉风格和具体标签，形成有依据的设计定位。
3. [数据搜集](./03-数据搜集/README.md)：整理公共数据集、文本文献和自建数据集，记录来源与可信度。
4. [基础数据集构建](./04-基础数据集构建/README.md)：建立规范、可复用的基础数据表；每一列只对应一个数据项/字段，不在单元格中混装多个数据。
5. [叙事框架搭建](./05-叙事框架搭建/README.md)：组合若干字段，形成清晰的叙事主题和信息关系。
6. [视觉编码](./06-视觉编码/README.md)：重点研究设计表达，将数据与点、线、面、体、色彩、文字、图像、统计图形及ISOTYPE等视觉变量建立对应。
7. [信息轮盘测试](./07-信息轮盘测试/README.md)：测试方法与评价标准待后续补充。
8. [设计实施](./08-设计实施/README.md)：完成草图、版式、视觉细化、输出和归档。

## 重要工作原则

- 区分**来源事实、数据处理结果、分析判断、设计假设**，不把推断写成事实。
- 每条数据尽量保留来源、时间、单位、口径和必要的备注。
- 基础数据集与叙事使用的数据组合分开管理：前者保证字段清晰，后者说明字段如何共同表达主题。
- 不预设作品一定属于某一种信息图类型或风格；类型与标签应由主题内容、数据条件和表达目标共同决定。
- 视觉编码应说明“什么数据对应什么视觉形式”，并记录选择理由。
- 需要核实的信息明确标记为“待核实”，不要用猜测补齐。
