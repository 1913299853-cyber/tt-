# 04 基础数据集构建

本阶段将多来源材料整理为结构清楚、可检查、可继续加工的基础数据集。

## 核心字段规则
- **一列只表示一个字段/一种数据项。**
- **一个单元格只放一个数据值**，不要把多个名称、多个数字或多段内容塞进同一格。
- 每一行代表一个明确的数据记录/观察对象。
- 名称、类别、日期、数值、单位、地点、文本、图像路径等应拆分为独立字段。
- 名义数据、量化数据、图像数据、文本文字数据均可纳入，但须明确字段类型和记录规则。
- 不同类型的数据不要混在同一字段中；需要关联时使用稳定的ID或关联字段。
- 缺失值、未知值、不适用值应有统一标记规则，不得用0随意代替。

## 字段说明表
建议为每个字段记录：字段名、含义、数据类型、单位/格式、允许值或编码规则、来源、是否必填、缺失值规则、示例。

## 阶段产出
- 原始数据副本
- 清洗后的基础数据表
- 数据字典/字段说明表
- 数据质量检查记录
