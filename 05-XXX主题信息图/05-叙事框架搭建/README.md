# 05 叙事框架搭建

从基础数据集中选择若干字段，建立能表达明确主题的信息组合。叙事字段组合不是随意拼接，必须说明字段之间的关系以及它们如何支持核心观点。

## 叙事组合示例
- 名称 + GPS坐标 → 地图上的地点及其空间分布
- 名称 + 数值 → 某地GDP、人口或其他指标的比较
- 事件名称 + 日期 → 事件时间轴
- 对象名称 + 类别 → 分类目录或编目结构

## 每个叙事方案需要说明
1. 叙事主题/核心句
2. 使用哪些字段（对应基础数据集字段名）
3. 字段之间的关系
4. 读者应看到什么信息或得出什么理解
5. 适合的阅读顺序与信息层级
6. 需要的统计计算、筛选或排序
7. 数据是否足以支撑该叙事
8. 可能造成的误读与限制

## 阶段产出
至少形成一个主叙事方案；如有必要，保留备选方案并比较其信息表达效果。
