# 03 数据搜集

数据来源分为三类，分别归档，并建立统一的数据来源登记表。

- [公共数据集](./01-公共数据集/README.md)：政府开放数据、机构数据库、研究数据平台等。
- [文本文献](./02-文本文献/README.md)：书籍、论文、报告、档案、新闻及其他文本资料。
- [自建数据集](./03-自建数据集/README.md)：通过观察、访谈、测量、人工标注或程序采集形成的数据。

## 来源登记字段建议
来源编号、名称、发布者/作者、发布日期、获取日期、链接/馆藏信息、数据范围、统计口径、授权/使用限制、可靠性备注。

## 原则
保留原始文件，不覆盖原始数据；记录清洗、筛选、转录和补录过程；对缺失、冲突和无法核实的信息作出标记。
