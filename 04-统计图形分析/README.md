# 04-统计图形分析

本目录用于分析和理解信息图形案例中所使用的统计图形，重点关注图形背后的数据结构、统计关系与表达方式。

## 分析范围

后续结合具体信息图形案例，逐步识别和分析：

- **数据结构：** 数据单元、字段、变量类型、分类方式及数据之间的关系。
- **统计目的：** 图形试图回答什么问题，表达比较、分布、构成、变化、关联还是其他关系。
- **统计图形：** 案例实际使用了哪些统计图形或图表结构。
- **计算与转换：** 计数、求和、平均、比例、比率、排序、区间划分、标准化等处理方式（以案例证据为准）。
- **视觉编码：** 位置、长度、面积、角度、颜色、形状、大小等视觉元素如何对应数据。
- **阅读与解释：** 图形如何引导比较、识别趋势，并传达信息。

## 分析原则

1. 以仓库中的信息图形数据逻辑文档和具体案例为基础。
2. 区分原始数据、统计计算、图形表达与视觉叙事，不把装饰性布局直接认定为统计图形。
3. 区分画面中可直接观察的事实、基于证据的分析判断，以及仍需核实的内容。
4. 不预先把某一种图表或计算方法认定为案例事实；逐案记录，再归纳共性。
5. 分析成果可回链到 `01-信息图形数据逻辑` 和 `02-信息图形类型案例` 中的相关文档。
